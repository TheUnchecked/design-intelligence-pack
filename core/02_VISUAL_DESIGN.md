# Design Intelligence Pack — Visual Design

## Purpose

Define the visual principles used to create clear, coherent and intentional digital interfaces.

Visual design must support:

- comprehension;
- hierarchy;
- usability;
- brand expression;
- accessibility;
- consistency.

Visual styling must never compensate for weak information architecture or poor UX.

---

## 1. Visual Hierarchy

Visual hierarchy determines what the user notices first, second and third.

Establish hierarchy using:

- scale;
- weight;
- spacing;
- position;
- contrast;
- alignment;
- color;
- density.

### Rule

Use the minimum number of visual signals necessary to establish clear hierarchy.

### Avoid

- making everything prominent;
- excessive bold text;
- excessive color;
- competing CTAs;
- arbitrary visual emphasis.

---

## 2. Typography

Typography is structural, not decorative.

Define:

- primary typeface;
- secondary typeface when justified;
- type scale;
- font weights;
- line height;
- letter spacing;
- paragraph width;
- heading hierarchy.

### Rules

- Use a limited type system.
- Establish a clear relationship between headings and body text.
- Prioritize readability.
- Maintain consistent hierarchy.
- Test typography across viewport sizes.
- Use font weight intentionally.

### Avoid

- excessive font families;
- excessive font weights;
- tiny body text;
- decorative typography that reduces readability;
- arbitrary font-size changes.

---

## 3. Color

Color should communicate hierarchy, state, identity or meaning.

Define:

- primary colors;
- secondary colors;
- neutral palette;
- semantic colors;
- interaction states.

### Rules

Use color intentionally.

Every prominent color should have a purpose.

Consider:

- contrast;
- accessibility;
- brand consistency;
- semantic meaning;
- light/dark contexts.

### Avoid

- decorative gradients without purpose;
- excessive accent colors;
- using color as the only indicator of meaning;
- low-contrast text;
- trend-driven palettes without context.

---

## 4. Spacing

Spacing creates relationships between elements.

Use spacing to communicate:

- grouping;
- separation;
- hierarchy;
- rhythm;
- density.

### Rules

Prefer a consistent spacing system.

Related elements should generally be closer together than unrelated elements.

### Avoid

- arbitrary margins;
- inconsistent gaps;
- cramped content;
- excessive whitespace without purpose;
- every section using identical spacing.

---

## 5. Layout

Layout establishes the structure of the interface.

Consider:

- grid;
- alignment;
- container width;
- columns;
- whitespace;
- content density;
- visual rhythm.

### Rules

- Establish a clear primary axis.
- Align related content.
- Maintain consistent container behavior.
- Use whitespace deliberately.
- Let content determine layout requirements.

### Avoid

- unnecessary cards;
- nested cards;
- excessive columns;
- symmetrical layouts where asymmetry improves hierarchy;
- decorative containers without semantic purpose.

---

## 6. Alignment

Alignment creates visual order.

Prefer deliberate alignment across:

- headings;
- paragraphs;
- controls;
- cards;
- images;
- navigation;
- sections.

Misalignment should be intentional, not accidental.

---

## 7. Density

Visual density affects cognitive load.

Evaluate:

- amount of information;
- spacing;
- number of components;
- text length;
- competing visual elements.

### Rule

Match density to context.

A dashboard, editorial page and marketing landing page do not require the same density.

---

## 8. Components

Components should behave as parts of a coherent system.

Define consistent rules for:

- buttons;
- inputs;
- cards;
- navigation;
- alerts;
- forms;
- menus;
- links.

Consistency should include:

- dimensions;
- spacing;
- typography;
- color;
- states;
- interaction behavior.

---

## 9. Imagery

Images should support the communication goal.

Evaluate:

- relevance;
- composition;
- aspect ratio;
- visual quality;
- accessibility;
- consistency with brand.

### Avoid

- generic stock imagery when it weakens authenticity;
- decorative imagery that competes with content;
- inconsistent image treatment;
- images without meaningful purpose.

---

## 10. Depth and Effects

Use:

- shadows;
- borders;
- gradients;
- blur;
- transparency;

only when they improve hierarchy, separation or interaction feedback.

### Avoid

Effects added purely to make an interface appear "modern".

---

## 11. Responsive Visual Design

Visual hierarchy must survive different viewport sizes.

Validate:

- typography scaling;
- spacing;
- content order;
- image behavior;
- navigation;
- component width;
- touch targets;
- overflow.

Mobile layouts may require structural changes, not just smaller dimensions.

---

## 12. Motion

Motion should communicate:

- state;
- transition;
- spatial relationship;
- feedback;
- continuity.

### Rules

- Keep motion purposeful.
- Respect reduced-motion preferences.
- Avoid animation that delays or obstructs interaction.
- Use consistent timing and easing.

### Avoid

- animation everywhere;
- decorative motion without purpose;
- excessive bouncing;
- long transitions;
- motion competing with content.

---

## 13. Visual Quality Check

Before considering visual design complete, verify:

### Hierarchy
Can the user identify the primary message immediately?

### Typography
Is the text readable and structurally consistent?

### Color
Does color communicate meaning without creating accessibility problems?

### Spacing
Are relationships between elements clear?

### Layout
Is the composition coherent?

### Components
Are repeated elements consistent?

### Density
Is the interface cognitively manageable?

### Responsive
Does the hierarchy survive across viewport sizes?

### Intent
Does every significant visual choice have a reason?

---

## Visual Design Principle

**Good visual design makes the intended meaning easier to understand.**

If visual styling attracts attention but reduces comprehension, usability or accessibility, the styling is unsuccessful.
