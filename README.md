# Design Intelligence Pack

A vendor-neutral framework for AI-assisted design reasoning.

## Purpose

Design Intelligence Pack helps AI systems understand, design, critique,
audit and improve digital experiences using structured design principles.

## Goals

- Improve AI-assisted design quality
- Reduce generic and repetitive AI-generated design
- Make design decisions explicit and explainable
- Provide a reusable design reasoning framework
- Remain independent from any AI vendor or platform

## Compatible With

The core framework is designed to work with:

- Claude
- Microsoft 365 Copilot
- ChatGPT
- Gemini
- GitHub Copilot
- Other LLM-based systems
